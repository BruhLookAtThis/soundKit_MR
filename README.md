THIS PROJECT MAY SOON-ISH BE ABANDONED
--------------------------------------------------------------
1. A new tool, [XzoundWave](<https://github.com/X-zant/XzoundWave-Rivals-Sound-Toolkit/releases>), made by **XzantGaming** (the creator of [Repak-X](<https://github.com/XzantGaming/Repak-X>), will replace soundKit for most, if not all of yall. Here is a [quick tutorial](<https://www.youtube.com/watch?v=8LuEU-JBZhI>) for it
2. It offers a much easier, faster, and smoother audio modding experience than soundKit, so please give it a try when you can
3. It (hopefully) will implement all features of the soundKit Beta, but right now the majority of what the average user needs is already implemented.
4. More time will be needed to add the more niche/advanced tricks from the soundKit Beta, but thats largely only a concern for myself
5. Once that project is "fully completed" in that sense, I will largely abandon soundKit, as it will no longer be needed or recommended to use
6. This page will remain up though, in case we need to fall back to soundKit for some reason in the future

OVERVIEW
--------------------------------------------------------------

(GRAB AN FMODEL DOWNLOAD FROM HERE: https://fmodel.app/download)

1. Written instructions are included

2. The SDKT (Soundkit Modding Tool) folder is for:
   
   a. Extracting and labeling most character voices (+ some Emote, MVP, Lobby, etc SFX) from the game

   b. Extracting and organizing most, if not all, character voice subtitles from the game
   
   c. Replacing most English character voices with their Japanese or Chinese counterparts

   d. Replacing ingame audio files with your custom files

   e. Extracting vanilla audio files from bnk files

   f. Other, miscellaneous operations
   
   AUDIO THAT HAS BEEN LOGGED CAN BE [FOUND HERE](<https://docs.google.com/spreadsheets/d/14gbnE0TD2O4e8zrn2jSJm9HsNl5vWxFYWm4ZsndQJlA/edit?gid=0#gid=0>)

5. The \0_DATA\1-MISC-STUFF\ folder contains:
   
   a. Various misc tools that may assist you in the modding process. Each contain their own instructions.
   
   b. A Marvel Rivals .usmap (from the Marvel Rivals section of the 'game compatibility' support channel in https://discord.gg/fmodel )
   
   c. FModel AES key for Marvel Rivals

MAKE SURE YOU READ THE INSTRUCTIONS (If theyre outdated, they will be labeled as so)
